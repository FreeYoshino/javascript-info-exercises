# javascript-info-exercises

記錄我的 JavaScript 與 Node.js 學習歷程。
包含 javascript.info 的課後練習題。

歡迎來到我的學習倉庫！

目前的練習題目主要來自於 [The Modern JavaScript Tutorial (javascript.info)](https://javascript.info/)。

## 📚 倉庫結構 (Structure)

```text
.
├── part1-js-language/        # [核心必讀] Part 1: The JavaScript Language
│   ├── 02-fundamentals/      # JavaScript 基礎 (Variables, Loops, Functions)
│   ├── 04-objects/           # 物件 (Objects: the basics)
│   ├── 05-data-types/        # 資料型態 (Data types)
│   ├── 11-async/             # 非同步處理 (Promises, async/await) 🔥 Node.js 重點
│   └── 14-misc/              # 其他雜項 (Proxy, Eval...)
│
├── part2-browser/            # [選讀] Part 2: Browser: Document, Events, Interfaces
│   ├── 01-document/          # DOM 操作 (Node.js 環境較少用到)
│   └── 02-events/            # 事件處理
│
├── part3-additional/         # [進階] Part 3: Additional articles
│   ├── 03-network/           # 網路請求 (Fetch, WebSocket)
│   └── 07-regex/             # 正規表達式 (Regular Expressions)
│
└── README.md
```
